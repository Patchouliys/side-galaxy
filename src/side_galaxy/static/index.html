01 / 实验链路

从文件到板卡

  1. 上传 ZIP，服务器校验并保存 SHA-256 版本。
  2. 选择板卡、参数和资源，原子预检后提交。
  3. 板端代理拉取任务与制品，交由固定版本模块执行。
  4. Linux 运行进程；KVM 通过 QEMU guest agent 在 VM 内执行。
  5. 回传最终日志、退出码和声明的输出文件。

KVM guest 需要 Python 3 与 QEMU guest agent。日志在任务结束后回传，输出总量上限 512 KiB。模拟器仅验证分发。

02 / 命令行

可脚本化的实验

sg boards
sg artifacts
sg pack experiment/ --output experiment.zip
sg artifact-upload experiment.zip
sg preflight plan.json
sg submit plan.json --key experiment-001
sg batch <batch-id>

使用 SG_SERVER 指向服务器，SG_TOKEN 提供访问令牌。

03 / AI 接入

MCP stdio

sg mcp
# 允许 AI 提交、取消与重载
sg mcp --allow-writes

将 sg 设为 MCP 客户端 command，["mcp"] 设为 args。默认只读；写入仍受服务器令牌与准入约束。

04 / 模块与部署

按板型与系统扩展

板型描述、系统配置与执行模块各自独立。代理使用本地配置连接服务器，额外 profiles 通过 --profiles-dir 加载。

仓库的 deploy/ 提供容器与 Ansible 部署入口。安装细节、私密清单与真机验收步骤见 docs/operations.md。
