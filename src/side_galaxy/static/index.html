物理 Linux 设备

注册并启动板端代理

先安装与板端架构兼容的 Side Galaxy。控制机列出可选配置，再注册设备：

sg profiles
sg enroll --name board-lab \
  --board-profile generic \
  --system-profile linux-process \
  --output .data/board-agent.json

通过安全连接将私有配置传到板端，并将其中 server 设置为板端可访问的控制面地址。随后在板端启动：

sg agent --config board-agent.json

配置包含设备令牌，请限制文件权限并排除 Git。USB 网络和局域网均可接入；控制面远程监听需配置访问令牌，不能直接使用仅回环地址。KVM 或离线环境模块还需要预装相应运行时。普通 Linux 进程实验可先使用 linux-process。

本地实验环境

启动 QEMU Linux 目标

sg lab up
sg lab status
sg lab down

在本机终端运行。需要 QEMU 与 SSH 工具。首次启动会下载约 325 MB 镜像并在 guest 内构建，耗时较长；代理就绪后会出现在设备列表。

代码到结果

实验执行链路

  1. 上传 ZIP，保存 SHA-256 版本。
  2. 选择设备，配置参数和资源。
  3. 预检通过后原子受理，代理拉取制品并执行。
  4. 执行中查看实时输出，结束后读取退出码与输出文件。

Linux 使用进程模块；KVM guest 需要 Python 3 与 QEMU Guest Agent。实时日志保留量有限，最终日志独立回传；输出总量上限 512 KiB。
