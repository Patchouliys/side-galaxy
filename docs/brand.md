# Side Galaxy Visual Guide

Side Galaxy uses an edge-on galaxy as its metaphor: a stable, bright management core, observable resource orbits, and distant groups of independently running board stars.

Identity asset: `src/side_galaxy/static/icon.svg`, a native 64×64 vector. Intersecting ellipses represent the disk and observation orbits, with a four-point bright core at the center and a separate star in the upper-right. It serves as the favicon, sidebar icon, and application identity. `galaxy.svg` is the 1000×350 main edge-on disk illustration. Both are original project SVGs, without externally hosted fonts, images, or telemetry.

The logo combines the icon with the lowercase `side galaxy` wordmark and an "Edge-on Galaxy / CONTROL PLANE" subtitle. Colors: deep-space background #091118, panels #0E1A24, cyan core #8BE5CD, distant-star blue #9EAFF3, warm white #E3EDF0, and warning amber #EDBD80. Normal statuses use both text and symbols and must not rely on color alone.

The management interface omits large disk illustrations, slogans, and repeated decorative English headings; the main visual assets remain available for brand material. It uses system fonts, with monospace for numbers and version hashes. Use restrained outlines, orbits, thin borders, and meaningful experiment states. Synthetic boards display SIMULATED, and synthetic values are not presented as live telemetry.
